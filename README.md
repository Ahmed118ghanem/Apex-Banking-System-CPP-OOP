Apex Banking System — C++ OOP

A console-based banking system developed using C++ and Object-Oriented Programming (OOP).

Features

Client management

Add, update, delete, and search for clients

Deposit and withdraw money

Transfer money between clients

View transaction history

User management and login system

Currency management and exchange rate calculator

Total balances overview

Technologies Used

C++

Object-Oriented Programming (OOP)

Visual Studio

Getting Started

Clone or download this repository.

Open Bank_System_By_OOP.sln in Visual Studio.

Build the solution.

Run the project.
